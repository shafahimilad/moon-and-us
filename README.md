# Moon&Us 🌙

تقویم پریود و چرخه برای دو نفر — الهام‌گرفته از امکانات Clue، با هویت و طراحی خودمون.

## امکانات
- **امروز:** دایره چرخه، روز چرخه، شمارش معکوس تا پریود، فاز فعلی، پیش‌بینی PMS / باروری / تخمک‌گذاری
- **ثبت روزانه:** خونریزی، درد، احساسات، انرژی، خواب، رابطه، ترشحات، هوس، گوارش، پوست، ذهن، اجتماعی، ورزش، دارو، تست، دمای پایه بدن، یادداشت
- **پیش‌بینی علائم:** از روی چرخه‌های قبلی می‌گه چه علائمی احتمالاً این روزها میاد
- **تقویم شمسی/میلادی** با روزهای پریود، پیش‌بینی، باروری و PMS + ویرایش سریع تاریخچه
- **تحلیل:** میانگین چرخه و پریود، نظم چرخه، نمودار، تاریخچه، جدول «علائم در هر فاز»، خلاصه برای پزشک
- **ما دوتا:** حال و نیازهای امروز، راهنمای پارتنر برای هر فاز، کیت مراقبت، دیوار یادداشت‌ها
- **هدف:** فقط پیگیری / بارداری نمی‌خوایم / اقدام به بارداری
- **حریم خصوصی:** همه داده‌ها روی خود گوشی، قفل رمز، پشتیبان‌گیری، همگام‌سازی دو گوشی با کد
- **افزودن به تقویم گوشی** (فایل .ics با یادآور)، حالت تیره، نصب به‌شکل اپ (PWA)، کار بدون اینترنت

## اجرا روی کامپیوتر
```
python -m http.server 5173
```
بعد `http://localhost:5173` رو باز کنید.

## نصب روی گوشی
برای نصب روی گوشی، پوشه رو روی یه هاست HTTPS رایگان بذارید (مثلاً GitHub Pages یا Netlify Drop)، لینک رو در مرورگر گوشی باز کنید و «Add to Home Screen» رو بزنید.

> پیش‌بینی‌ها تقریبی‌اند و جایگزین مشاوره پزشکی یا روش پیشگیری از بارداری نیستند.
